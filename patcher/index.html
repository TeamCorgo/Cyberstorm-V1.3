Missionforce: Cyberstorm V1.3 Patcher

Adds the community patch to your copy of the game. Everything happens locally in your browser; nothing is ever uploaded. The community patch cannot be played without the user owning a copy of Missionforce: Cyberstorm.

Result

How to install

  1. Convert your original game .exe.
  2. Download the zip file containing the V1.3 files.
  3. Extract the zip into the game folder.
  4. Let the patched CSTORM.EXE replace the original.
  5. Launch the game and configure the options from the in-game menu (Help → Mods).
